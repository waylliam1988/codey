Conversation Navigation Rail IMPROVE

The quiet vertical tick rail in the left reading margin

Navigation Ticks
How should I implement the conversation navigation rail?

The navigation rail sits in the left reading margin when the conversation has at least four user messages. Each tick represents one user question and its reply. The current position uses the green --nav-current token.

On hover, nearby ticks expand in a gentle wave. After 220ms, a dark tooltip shows the question preview. Click to jump.

Key improvements:
• Proximity wave — Ticks near the current position and near the hover target get slightly wider, creating a smooth wave effect.
• Green current marker — Uses --nav-current (the shared green) for the reading position. Other ticks are --faint.
• Hover preview — After 220ms delay, shows question text + reply excerpt in a --panel-2 tooltip. Prevents accidental previews.
• No layout shift — The rail sits in the margin without affecting content width. Hidden when margin < 48px.

Summary of Recommendations

All changes stay within the approved DESIGN.md language:

1. Sidebar — Tree indentation lines, unread dots, project file count badges.
2. Messages — Subtle left border on user messages, better paragraph spacing (24px vs 18px).
3. Process Disclosure — Left border accent (turns green when active), continuation tree lines for tool activity.
4. Tool Lines — Hover backgrounds for better scannability.
5. Code Blocks — Dedicated header bar separating language label from code content.
6. Status Rows — Very subtle background tint to visually separate from message flow.
7. Run Details — Subtle bordered container instead of raw left margin indent.
8. Shell Approval — Left accent stripe on pending approvals, split Allow button.
9. Command Results — Hover feedback on collapsed rows.
10. Diff Drawer — Mini bar charts for file change stats.
11. Composer — Keyboard shortcut hints on focus, better attachment chip layout.
12. Settings — Smoother toggle animation, custom checkboxes matching monochrome language.
13. Empty State — Character pond with green ripples, centered composer.
14. Question Cards — Option descriptions, better radio alignment.
15. Nav Rail — Proximity wave on ticks, hover preview with delay.

Principles maintained:
• Monochrome first — no new colors. All tints use existing --green-rgb, --err-text, and neutral tokens.
• Quiet by default — improvements are revealed on hover/focus, not always visible.
• No decoration — no emoji, no gradients, no colored buttons.
• English UI chrome — all labels and copy in English.
