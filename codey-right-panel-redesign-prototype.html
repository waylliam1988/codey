1. Workspace Shell — 工作区外壳

工作区外壳包括 tab 栏、resize handle、展开/收起按钮。
改进点：(1) Tab 底部下划线改为 2px 宽、带 inset 效果更精致；(2) 新增 close 按钮让 tab 可关闭；(3) 新增 badge 显示 tab 内信息量（如来源数量）；(4) 图标按钮统一尺寸和圆角。

设计改进总结

核心原则：遵循 DESIGN.md 的单色调 + green accent 视觉规范，所有改进在现有设计语言内进行优化。

1. 信息层级更清晰
• Evidence 卡片通过 stance 色彩编码（左边框 + badge）让用户快速区分支持/反驳证据
• Source 卡片通过 favicon + 编号 + tag 分层展示，降低扫描成本
• Local Context 组头部的 chevron + count 让结构一目了然

2. 操作效率更高
• Tab 可关闭，减少不需要的面板占用
• Local Context 行级操作从 ⋯ 菜单改为 hover 直接显示，减少一次点击
• Document Pane 增加工具栏（搜索、source/rendered 切换、复制），常用操作触手可及

3. 视觉一致性
• 所有引用文本统一使用斜体 + 左边框 + 淡背景样式
• 所有 tag/badge 统一使用 var(--panel-2) 背景 + var(--text-dim) 文字
• 所有 hover 效果统一使用 var(--hover) 背景，transition 0.12s
• 下划线指示器统一为 2px + inset 8px + var(--text-dim) 色

4. 空间利用更好
• Note 预览默认折叠 (80px)，按需展开，避免长笔记占据整个视口
• Graph detail panel 固定在底部，不遮挡 canvas 操作
• 面包屑路径单行显示，不额外占用纵向空间

5. 保持的设计约束
• 无 emoji 用于交互控件（文件图标除外，实际实现应使用 SVG icon）
• 无彩色按钮、无渐变
• Green 仅用于：graph nodes、diff adds、stance supports、ok-dot
• 所有按钮无边框，仅文字 + hover 背景
• 英文 UI 标签
