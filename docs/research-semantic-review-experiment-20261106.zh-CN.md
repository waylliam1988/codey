## 预注册（模型运行前）

1. 实验对象是诊断器，不是最终答案生成器；不声称离线诊断收益等于端到端 Research 收益。
2. 当前生产仅校验引用结构，语义状态应为未审查；其语义告警召回率为零，但不能把它的静默伪造为 `entailed`。
3. A：同一输入、同一 JSON 合同下的简短通用证据审查。B：受控语义审查，明确条件、版本、量词、反向推理、复合句、材料范围、合理跨来源推论和无引用断言。
4. 人工编写金标，先冻结再运行；8 个开发报告、8 个保留报告，各两个种子。保留集运行前不改提示或评分。每个报告含正确及错误断言、非事实文本。全部材料为合成事实，避免依赖模型记忆。
5. 从原始 Markdown 按完整行定位断言，保存准确起止位置、正文与证据摘要。模型只能返回原位置 ID 的 verdict，不能改写被检查句子。
6. 金标不发给模型。四类：`entailed / partially / contradicted / unverified`；非事实文本为 `not_claim`。不检查来源真实性，只检查给定材料支持关系。
7. 主要指标：错误断言告警召回、正确断言误报、四类准确率、断言识别召回、无引错误检出；同时报告格式失败、token、时延。禁止靠删除断言提高通过率。
8. 候选最低门槛：保留集错误检出 ≥85%，正确断言误报 ≤10%，格式有效率 100%；相对 A 的准确率或检出至少提高 5 个百分点且误报不增加。重复种子不是独立题目，不进行伪显著性论证。
9. 即使通过也先扩展鲁棒性及真实历史答案回放；发布前修订、异步预算与恢复未验证前，不接入生产 gate。
