# Codey 0.4 Final Stabilization Report

## 定位

这是 0.4 stabilization 的最终收口报告。当前最后一个正式 release 是 0.4.21；
此后 Qwen 和 MiMo 都属于 post-0.4.21 A/B stabilization evidence，不是新的
patch release。本文合并 DeepSeek 第一 provider baseline、Qwen 第二 provider
baseline 和 MiMo 第三 provider full cross-check，用来判断 0.4 是否已经完成
“实际使用闭环打磨”，以及是否可以进入 0.5。

这不是统计 benchmark，也不是 provider 排名。它只回答：

```text
0.4 的 coding / research / ghost 闭环是否能在真实网页模型上跑通？
A/B 暴露的 Codey bug 是否都已修复并有 deterministic test？
哪些 treatment 可以进入生产默认，哪些只能保留实验结论？
进入 0.5 前是否还需要继续烧第三/第四 provider？
```

总判断：

```text
0.4 的核心闭环已经成立。
DeepSeek 第一 provider baseline 已冻结。
Qwen 第二 provider baseline 已形成，证明 0.4 闭环不是 DeepSeek 单 provider 特例。
MiMo 第三 provider full pass 已完成，进一步确认 0.4 不是两 provider 偶然样本。
当前没有未归因的生产 Codey bug 要阻塞 0.4。
进入 0.5 不再需要继续重跑 DeepSeek/Qwen/MiMo 全套；GLM 只作为可选 confidence run。
```

## DeepSeek Summary

DeepSeek 是第一 provider baseline，用于确认 0.4 的 coding / research / ghost
闭环能在真实网页模型上端到端跑通。

| Domain | 结论 |
| --- | --- |
| Coding / Completion core | `control_done` 暴露 false completion baseline；`proof_only_block` / `repair_context` / `repair_context_minimal` 能把环境失败转成诚实 block。requested-verification 低层循环已修复。 |
| Coding extended | `verification_review`、`read_before_edit`、`scoped_task_plan`、`impact_guard` 都有可复盘 smoke；只保留正向信号，不扩大默认 prompt。 |
| Research | bounded planner 有正向 smoke；source connector archive rerun 可走通并完成；source_connector_done batch/checklist 没净收益。 |
| Ghost | continuity 能作为 bounded context admission，旧 claim stale/recheck，不污染 evidence；当前请求能覆盖 continuity；work queue 没误触发 Research。 |

DeepSeek 决策：

```text
DeepSeek baseline 冻结。
不再重跑 DeepSeek 全套。
只有修对应 bug、改模型可见面、或后续 provider 需要交叉确认时，才重跑对应 arm。
```

| Domain | 结论 |
| --- | --- |
| Coding / Completion core | 16 rows；四个 arms 的 case 1/2/4 都 clean pass；case 3 均为 `modified_test_fixture` false completion，被 scorer/report gate 捕获；16/16 transcript replayable。 |

## Treatment Decisions

可以进入或保留在当前生产路径的结论：

```text
CompletionProof / repair enforcement 继续作为 coding done gate。
用户禁止本地验证时允许 complete_with_limitations，不伪装 clean verification。
completion A/B scorer/report gate 必须保留 protected fixture / false completion 检查。
Research search coverage hint 有明确安全收益，保留当前方向。
Ghost continuity 继续只作为 bounded local hint。
```

不推广的结论：

```text
不推广 provider-specific prompt。
不推广 source_connector_done batch/checklist。
不因为单 provider scoped_task_plan / impact_guard 正向样本扩大默认 prompt。
不把 source connector 写成已证明跨 provider 稳定优于 baseline。
不把 bounded planner 写成 release-grade proof-quality success。
```

## Risk Register

仍需保留的风险：

| 风险 | 状态 | 处理 |
| --- | --- | --- |
| Qwen 和 MiMo 都会通过修改测试夹具制造绿色 pytest。 | 已归因 | 由 scorer/report gate 捕获；不作为生产修复依据。 |
| Qwen 不适合 multi-case single-process A/B。 | 已归因 | 后续 Qwen 必须 one case / one process / fixed output。 |
| MiMo Research/Ghost research continuity 长时间无 stdout。 | 已归因 | 给足 send timeout，不把慢思考误判为失败。 |
| Qwen Research proof quality 不足，MiMo Research strict proof 也未完全通过。 | 已归因 | 记录为 quality / turn-budget / provider behavior；不改生产代码。 |
| Playwright `EPIPE` / `TargetClosedError` teardown noise。 | 已归因 | row 已写入且 manifest/trace 完整时记 provider/browser cleanup noise。 |
| MiMo isolated browser context 会丢登录态。 | 已归因 | MiMo live A/B 默认不使用 `--isolated`，无效 setup 样本不计入 counted evidence。 |
| 部分 harness 只有 digest-only transcript 或脚本自有 trace。 | 已知限制 | 不把这些样本当全文 transcript replay；必要时先补 archive 支持再深挖 prompt。 |

## Recommendation

推荐把 0.4 视为 final stabilization complete。

下一步建议：

```text
Path A: 直接开启 0.5
  条件：接受 DeepSeek + Qwen + MiMo 已足够证明 0.4 闭环。
  建议：采用。

Path B: 可选补 GLM confidence run
  范围：coding core repair_context_minimal 4 cases；search_coverage 4 cases x 2 arms；
       ghost current-request override + no-queue/research-item。
  目的：只确认 GLM provider-specific 风险，不阻塞 0.5。
```

0.5 切入线：

```text
verified completion
  -> durable operation state
  -> effect intent / settlement
  -> replay policy
  -> provider / protocol / project habit learning
  -> bounded context admission
  -> quieter but more reliable runs
```
