# Codey UI/UX 实施记录

依据：[已确认规格](uiux_completion_spec_2026-10-20.zh-CN.md)、[原版功能保留清单](uiux_original_parity_audit_2026-10-20.zh-CN.md)及 `artifacts/uiux-preview/2026-10-20/` 中的交互对照稿。2026-10-20 开始修改真实前端；演示内容不能进入产品。

## 实施约束

- 使用现有 TypeScript 模块与 Codey 持久化/执行链路，不引入另一个会话真相或新框架。
- 保留项目/会话侧栏、Settings 内容、输入框原样式、绿色模型点与原发送 SVG。应用用户确认的项目行透明背景和折叠箭头规则。
- 保留原位编辑/重命名、草稿/选区、阅读位置、历史分页、工具展开、审批/问题恢复、Local context 和 Research 的完整行为。
- 真实可用能力才显示可执行操作。交互终端、计划审批等缺少服务契约的项目不允许以固定演示数据或假完成状态交付。
- 修改 `frontend` 源码，构建后使用发布工具更新 `codey/web`。

## 本次发现并修复的既有细节

- 图谱静止后休眠，拖动时只重绘抓住的节点；改为按下/移动即唤醒，拖动期间不休眠，保留原弹簧与 `0.86` 阻尼，并处理取消、丢失捕获和窗口失焦。
- `long.py:180` 被当成协议名，带行号的单独文件名不能点击；现在先解析行号再检查协议，HTTP/脚本链接仍不可冒充文件。
- 同类工具折叠时从 DOM 文本重建第一条记录，丢失其预览、截断说明和身份；现在保留原始展示记录。
- 后端已能放置 steer，但边界后仍会留下独立任务，且最终回答边界的返回文本被忽略；增加消费回执和继续生成路径，避免重复执行或吞掉插话。
- 重复打开 Changes 时，工作区的延后滚动恢复覆盖实时阅读位置；当前页重复 reveal 不再重新安排恢复。
- 文件加载中或面板隐藏时，空容器会把缓存的阅读位置写成零；只从可见且已载入的正文保存位置。文件位置由每个文件标签管理，工作区不再用另一份面板滚动缓存覆盖它。
- 搜索未加载的旧消息时，活动回答保留的临时记录可能挤出目标窗口最前面的原文；定位期间明确从该有界窗口起点渲染，仍保留流式节点身份。

## 不属于“已有后端、补前端”的能力

下列功能未在本次伪造入口，也不标为完成：交互式 PTY、项目文件编辑/完整目录树、图片粘贴和文件拖拽上传、任意网页预览、子代理任务目录/独立控制、持久计划审批、调度/远程连接/账户、可信 token/费用仪表、对话导出和公开共享。它们仍需要规格 C 表列出的服务、权限和生命周期契约。输入框继续不显示附件加号。

实际网页模型登录与所有模型组合的联调未由本次确定性服务测试替代。原生 Completions / Responses 的 HTTP、SSE、插话、排队、问题、停止和历史工作流由浏览器回归验证；原始截图、测试报告和构建记录保存在 `.e2e-artifacts/uiux-implementation/`。
