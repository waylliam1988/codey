# 左栏分组操作验证记录

日期为 2026-11-20。本轮直接使用当前工作区，未创建或复制 worktree。

## 修改

CHATS 右侧增加现有方框加笔图标，调用顶部 New chat 的同一操作，创建普通对话。PROJECTS 右侧增加共享 plus SVG，调用顶部 Add project 的同一文件夹选择流程。具体项目右侧的新建对话入口继续绑定该项目。

按钮在桌面默认隐藏，标题整行悬停或键盘可见焦点时显示，提前预留位置。悬停只提亮灰色图标。触屏常显，并使用 44px 点击目标。搜索隐藏分组时，其操作按钮同时隐藏。

本轮移除了 sidebar.ts 原有的两个 HTMLElement 类型断言，直接使用创建菜单按钮时已经确定类型的元素。

## 验证

- 前端严格 TypeScript、格式检查及全部 417 项 Vitest 通过。生产构建和发布内容校验通过。
- 六个相关 Python 测试文件首轮 61 项断言通过，覆盖新增分组入口、具体项目入口、普通对话归属、项目选择成功和取消、搜索、标题编辑及可读性。

- 新增浏览器测试检查标题行和按钮之间移动鼠标时持续可见、行尺寸稳定、键盘聚焦时显示和灰色焦点线、无按钮背景，以及触屏常显和 44px 点击范围。
- 项目选择使用真实本地 HTTP 入口，测试替换原生文件夹对话框返回值。成功和取消均返回 HTTP 200，原始请求及回执写入测试日志和测试临时目录。
- 全树 Ruff 通过。按仓库 CI 范围检查完整 codey 生产树，mypy、pyrefly 和 ty 均通过，目标 Python 3.11。mypy 检查 689 个源文件。Pyrefly 报告零错误，保留既有 35 项抑制和 165 项警告。
- 本轮新增及修改的两个 Python 测试文件分别通过 mypy、pyrefly 和 ty，未加入 Any、cast、type ignore 或检查豁免。
