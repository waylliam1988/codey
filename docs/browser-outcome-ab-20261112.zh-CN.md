# 浏览器回执文本交付与按记录就绪验收

生产基线为 `e3d876b0`。实验在独立 worker 内运行，使用生产任务入口、完成门、CodeMode、版本检查和真实 Chromium。生产源码、生产提示模板和配置保持原样。

## 对照设计

- `legacy_structured`。A 使用原来的纯文本任务，模型负责报告 URL 和 token。B 使用生产 `json_explanation` 及 `structured` 已有的 URL/token 回执绑定。模型提交说明，实验脚本把生产已验收的字段渲染成普通文本。两侧都验收真实浏览器操作、净重、校验码、精确 URL 和 token。A/B 的任务文字和输出合同因交付分工而异。
- `stale_edit`。A 保留原任务的成功 `browser_wait` 要求。B 把该要求换成「点击 Load record 后，在同一文档读取完整加载结果，再编辑」。B 在点击后的读取边界检查可见记录标记，已就绪时立即读页，否则在浏览器层等待至多 3 秒。两侧均审计写入前的点击和完整读取证据，并要求恰好一次真实版本冲突、冲突后重读、正确写入及保留外部字段。即时和延迟页面各跑一对，延迟页面在点击后 1.5 秒发布记录。

两对文本分别按 AB、BA 运行，即时编辑按 BA、延迟编辑按 AB。实机中模型自主选工具，未注入模型回复。定向回归另用脚本化回复复现 URL 转录错误、说明漏字段、缺真实 token、无显式等待的即时与延迟加载，以及点击后重载导致旧文档证据失效。测试夹具用「记录校验码」作为加载就绪标记，初始及加载中页面没有该标记。就绪证据在完成门校验，实验未把它接到每次文件写入的入场检查。

## 机制验证

- 同一个真实页面中，A 的脚本化说明把 URL 的连字符写成下划线，完成后事实验收失败。B 的说明省略 URL 和 token，生产完成层从真实回执绑定两个值，实验渲染保留原说明并添加精确的两行。缺 token 读取的 B 不产生文本交付。
- 即时页面中，两侧收到不含显式等待的同一组脚本化操作。两侧均发生一次真实版本冲突、重读并保留外部字段。A 因缺少成功的 `browser_wait` 无法完成，B 使用点击后读取证据通过。
- 延迟页面的 B 在读取内等待可见标记，真实等待超过 0.3 秒，后续完成文件冲突恢复，模型显式等待为零。点击后导航到相同 URL 的新文档时，B 拒绝把旧点击当作该次读取的前置证据。

41 项相关 pytest 通过，退出时有 RAM disk 清理告警。Ruff 和限定范围的 strict mypy 通过。

## 自主实机结果

| 配对 | A 原流程 | B 候选 |
| --- | --- | --- |
| 文本交付 1 | 通过，4 次请求 | `no_progress`，4 次请求 |
| 即时编辑 | `done`，无真实版本冲突，5 次请求 | 通过，5 次请求 |
| 文本交付 2 | 通过，5 次请求 | 通过，3 次请求 |
| 延迟编辑 | 通过，10 次请求 | `max_turns`，10 次请求 |

**文本交付 A 2/2、B 1/2，模型请求 9 → 7。** 第一对 B 四次卡在未定义的 `newSnapshot`，没有读取 URL 或 token。第二对 B 的两个展示值与原始工具回执逐字相同，模型的说明也包含了正确值，最终文本因此出现了重复。实机确认了实际交付路径，注入用例才直接证明省略精确字段后仍能交付。

**就绪验收 A、B 各 1/2，各 15 次模型请求。** 即时 B 没有显式等待调用，读取内就绪检查约 0.016 秒。通过回执审计确认同一文档点击后完整读取，随后发生一次真实版本冲突、重读和正确写入，保留了外部字段。即时 A 完成了显式等待，也写对了文件，但第一次有效编辑使用的是外部修改后的新读取，没有触发诊断要求的真实冲突。该配对的得分差异无法单独归因于等待要求。

延迟 B 也没有显式等待。三次读取内等待均成功，耗时约 1.36–1.47 秒，三个原始读页回执都有正确校验码。模型接着从 `result.json` 的原文件内容提取网页字段，首次正则匹配失败，随后把 `unknown` 写入目标字段。第一次写入前的浏览器序列缺正式导航回执，完成门也指出缺导航。最终没有真实版本冲突，磁盘值验收失败。这个单元确认浏览器层能等待并交付就绪正文，也暴露了正文与编辑值之间的交接缺口。

合计 **A 3/4、B 2/4**。两个机制分别有正例，当前矩阵没有显示端到端通过率收益。共审计 46 次实际请求，模型、seed 123456789、temperature 0 和非流式配置一致。八个单元完整结束，无服务失败或预算中止。生产摘要和两个实验脚本摘要前后一致。 [矩阵原始结果](../.e2e-artifacts/browser-outcome-20261112/summary.json) · [渲染文本](../.e2e-artifacts/browser-outcome-20261112/3-legacy_structured-B/rendered-answer.txt) · [延迟 B 的实际模型回复](../.e2e-artifacts/browser-outcome-20261112/4-stale_edit_delayed-B/provider.jsonl)
