# 权限、完成字段和后台验证收尾：修改与验证记录

本轮修复三处已复现的运行问题，并加强复杂任务的独立验收。没有新增模型工具、调用参数或第二套运行时。故障实验项目仍保留原始缺陷，正确实现只用于验收测试的校准和单独的验证实验。

## 修改

- `entry_auth.py`：明确允许修改一个文件时，“其他文件不动”不再撤销整个任务的写权限。保留真正的全局只读、禁止修改任何文件和明确冲突限制。文件名中的句点不再被当作句子边界。
- `tool_contract.py`、`kernel_protocol.py`：从编码完成合同中移除研究专用的 `source_gaps`，并在规范化时丢弃这个不适用字段。仍验证摘要、执行声明和其他适用参数；未知字段仍报错。研究合同不放宽，原始模型参数不被修改。
- `project_candidate_validation.py`：自动验证仍只启动一次原先授权的检查；长命令交还后台引用后，使用原内核等待正式结果，再提交完成。使用主任务剩余预算，取消、权限和停滞限制继续生效。不会重复运行命令，也不另开一套等待或执行机制。
- `kernel_context.py`：补上工具子任务正式收据到父任务汇总证据的投影。复用完成检查已有的投影函数，不伪造第二次工具执行事件。回归同时断言多次恢复不会重复计入检查。
- 实验验收新增“库存扣光后同一订单重试”和“订单连接显式关闭”。校准测试分别检查故障初稿、完整正确实现和泄漏连接的实现，确认验收能区分它们。
- 修正旧测试的快照版本、固定两步预算和字段适用性断言。只读实验改用实际测试进程写入的计数验证物理执行次数；不再依赖展示事件中缺失的时间字段。相关夹具补齐真实领域类型。

权限修复覆盖明确的中英文句式，不能理解任意自然语言，也没有新增逐文件权限系统。用户的文件范围要求仍应与编辑审计、独立文件检查一起验收。

## KoboldCpp / Gemma4 12B 实机

使用用户已有 KoboldCpp 1.117.1 服务和 Gemma4 12B，温度 0、seed 123456789、输出预算 4096、关闭思考。走生产连接与生产文本工具兼容路径，无人工继续提示。原始 HTTP 请求、回复、工具参数、正式收据、事件和独立测试结果均保留。

**复杂修复首轮：未通过。** 目录 `live-first/codey/`。任务继续使用曾触发误判的原句：`Change only checkout.py; do not change tests, API, database schema or other project files.`

- 权限正常，受保护文件未变。模型提交 5 次编辑，1 次成功，4 次旧文本不匹配而被拒绝；5 份工具参数都与原始模型回复完全一致。
- 模型阶段有 10 次工具回复；运行时自动验证另用 5 个逻辑步骤，最终总计 15 步，按正式失败结果停止。没有因为固定两步而提前结束，也没有把接纳回执当成测试通过。
- 独立加强验收为 **2 失败、10 通过**。仍失败的是库存耗尽后的同单重试和并发请求；连接关闭项通过。实机未走到后续诊断取消和健康检查，不能宣称综合任务完成。
- 编码原始请求中 `source_gaps` 出现次数为 **0**。

**独立后台验证：通过验证任务，不代表模型修复成功。** 目录 `live-verification-first/codey/`。程序在实验开始前放入正确实现，模型只负责启动后台测试、读文件、读取最终结果和提交完成。主任务 5 步后 `done`；独立验收 **12 通过**，文件未修改。

该只读任务的最终证明中，`execution_claims` 和必需工具要求通过，`relevant_verification` 为 `not_applicable`；最终汇总的 `checks_passed=false` 对应未授予“修改后相关验证”的证明，并不是子进程测试失败。没有为了让这个展示字段变绿而放宽完成合同。修改项目后的后台证据汇总由专门生产回归单独验证。

**历史完成回复回放：** 旧实验三份带 `source_gaps` 的原始完成回复，在新编码合同下都不再产生参数协议错误，原输入保留，只删除不适用字段。它证明原来的三次字段拒绝可以消除，不能据此宣称实机已经节省三个回合或业务修复合格。

## 收益与限制

已确定的局部收益：相同权限措辞可以进入正常编辑；模型不再看到编码任务不适用的研究字段；原始历史回复可以通过适用字段校验；自动验证能消费后台正式结果并拒绝错误修复。所有帮助都发生在现有调用内部，模型不需要多填任何参数。

尚未证明复杂任务总体成功率提高。本轮验收比历史新增两项，模型过程也不同，不能把新旧通过数直接当作公平 A/B。复杂实机中的业务缺陷和四次文本匹配错误仍属于模型输出问题，没有放宽编辑匹配或业务合同来迁就它们。

总预算仍然生效：只剩两步时，慢检查可能来不及完成收尾。后台取消、恢复和不重复执行由确定性生产回归覆盖；本轮复杂实机未完整覆盖这些后半程。未进行跨平台测试或全量 pytest。
