# 浏览器接续、真实网页与组合任务复核

日期：2026-11-22，Asia/Taipei。基线：`f7a7b839`。在原工作目录实施，没有复制仓库或创建 worktree。

本轮修复导航后的观察断线、研究视图遗漏当前 UI 状态，以及原生禁用状态展示不一致。真实网页操作、官方文档研究和两类组合自然任务分别验证；严格研究模式的动态按钮失败仍保留。全仓测试/工具类型债务仍未清零，不能宣称所有要求或任意网站验收全部通过。

## 顺序判据

**先浏览、修复后再做首次检查，可以闭环通过。** 只有用户明确要求“先检查并运行项目检查”的原 `repair` 任务才有相应顺序义务。不能把这份特定指令推广成所有修复任务的生产门禁。

本轮 `repair-flexible` 9 轮完成：取得网页实际记录、修改文件、首次项目检查成功、提交报告、完成。`repair_triggered_research=false`、`natural_task_closed=true`。原 `repair` 的历史失败和旧判据没有被重写；新任务也没有要求先制造一次失败检查。

## 确定性修复

1. **直接导航后没有当前控件。** `_lower_bound_inputs()` 原来只返回导航动作，最新文档使旧快照失效，模型必须自行补一次观察。现在直接导航复用既有 CodeMode 与原子回执，导航后自动快照，返回实际落地页面的控件。没有唯一任务 URL 时的普通 URL 导航也走同一合同；禁止快照时不增加观察。
2. **父失败遮住已完成导航。** 后续快照失败不改变导航回执。`_navigation_handoff()` 根据原提交记录提供当前页的观察入口，不重复导航；不把未知导航、别的文档或后续动作的恢复误说成导航恢复。没有新增 settlement、状态库或执行器。
3. **研究视图只留下快照编号。** 原视图保留操作元数据与 ref 参数合同，却可能移除快照中的“等待／下一步／完成”文字。`browser_observation_handoff()` 从同一个当前提交快照提供至多 4000 字符的 UI 文字，明确标记为引用数据、非指令、非引用证据，并保留截断标志。过期、未提交、控件不完整或回执截断的观察不展示；正文截断不取消完整控件绑定。正式研究引用仍来自原 passage 管线。
4. **冻结恢复遗漏新语义。** 请求版本升级为 14，共用 `TurnSnapshot.navigation_observes` 决定展示和 lowering。11–13 版本继续按原合同解释，未给历史请求追加新动作；source selector 的恢复判断同步支持 14。文本、原生协议和 JSON 恢复均覆盖。
5. **fieldset 禁用状态与执行不一致。** 官方文档研究引出并由真实 Chromium 复现：禁用 fieldset 内的 input，其 `el.disabled` 可以为 false，但 `:disabled` 为 true。快照以前提供不可执行的启用候选，执行器随后才拒绝。`ELEMENT_METADATA` 改用原生 `:disabled`，与现有动作检查及文件控件一致。首个 legend 内的例外、控件自身禁用及普通启用均有正反例；没有站点特例或猜测业务结果。

任务仍持有原 async 浏览器、统一 kernel、ToolSpec、授权、原节点身份和 effect 回执。快照失败不会重放已派发动作；截图和图像请求沿用原管线。没有更改命令白名单、来源字段合同、文件版本检查或报告接受条件。

网页操作与严格研究是分开的实验条件。原 `run_live()` 强制所有任务使用研究合同；现在支持显式 `--intent chat/research`，默认仍是 research，并在原 manifest 冻结实际 intent 和 strict_research。普通操作模式通过不能抵消上述三次严格研究失败。两种模式均用生产入口和原工具执行，新增脚本回归也检查真实点击、读取和原回执，不能仅凭 done 判成功。

两类文件任务是受控页面、真实 Chromium、真实本地模型及生产入口的实验；它们仍预声明两个来源→文件字段绑定和项目检查，不是任意网页字段自动推断实验。其基础浏览器 gate `passed=false` 原值保留：该指标还检查另一套固定工具步骤，独立的自然目标判据才是 `natural_task_closed`。没有删除失败指标或以新指标改写历史记录。

官方研究报告的主要问题及引文已对原文核查；第一份报告概括 disabled fieldset 时没有再次限定原文列举的原生控件类型，不能把引用资格当作任意表述的语义认证。两类项目完成事件仍显示 `verification limited / monitoring incomplete`，实际 unittest 成功不等于完整环境监控。

## 剩余边界与可继续减负的部分

- 动态按钮的严格研究自然任务仍未通过；普通模式成功也存在一次模型主动重复点击。程序正确保留已交付动作与当前状态，不代表模型总会选择等待而不是重复动作。
- 对未知下一控件，目前仍由模型选择明确的等待条件或重新观察。若继续减少 selector 抄写，应设计绑定原观察身份的控件状态等待合同，并验证超时、取消和恢复；不能用固定 sleep、自动重复点击或“页面有变化”冒充业务确认。本轮没有引入这套新合同。
- 任意自然语言任务并不自动获得正确的来源字段映射或全文语义认证。明确字段合同可确定性复制并保留值类型、来源与文件版本；没有映射时不能猜业务字段。真实登录、网站验证限制、任意网站成功与其他操作系统也未获得普遍保证。
