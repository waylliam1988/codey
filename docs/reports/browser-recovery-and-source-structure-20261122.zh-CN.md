# 浏览器循环恢复与来源结构验收（2026-11-22）

此前没有跑通的普通模式，现在已在自然任务实测和旧循环前缀恢复实测中完成动态按钮流程。严格研究模式也完成；两种模式均恰好 4 次点击、4 次动作后正式读取，最后来源确实包含 `All Buttons Clicked`。官方文档第三次实测完整报告了六项前置条件，并去掉了上一轮不受来源支持的 force 对照表。这里按原始请求、回执和正文验收，没有仅根据 `done` 判定成功。

## 根因和修改

| 问题 | 根因 | 本轮程序处理 |
| --- | --- | --- |
| 普通模式导航循环 | 控件和点击合同已送达，模型仍选导航；程序只提醒和到限退出，缺少恢复时的动作展示 | 同一请求/落地页、无其他交互且完整观察内容相同时，临时收起重复导航/快照的直接别名，展示原快照绑定的可执行控件；CodeMode 底层能力和原有预算保留 |
| 普通模式完成后缺正式来源 | 自动动作后读取此前主要接在研究模式；普通模式常只取得 UI 快照 | 将无必填参数的 `browser_read` 接进共享 `purpose=controls` 冻结计划，沿原链依次点击、限时等待、新快照、正式读取 |
| 文档推断混淆 | 原可见文本提取把标题、列表、表格压成一行，默认检查表与 force 说明没有结构边界；模型又将例子扩写成完整结论 | 同一可见 DOM 遍历支持结构化正式读取，保留标题、列表项、表格行/列、换行、原生 disclosure 和影子 DOM；原有紧凑 UI 观察保持原样 |
| 条件漏项 | 模型从长表格旁重建条件清单，漏掉表格分类外的“唯一匹配” | 工作视图从原 passage 投影列表原文和项数，供逐项核对；增加一般性的列表完整性/例子非穷尽指导，没有按 Playwright API 硬编码答案 |
| 查询来源绑定断开 | 新增结构边界后，记录/查询区域仍用另一种文本提取；后续包含检查只规范化了一侧空白 | 整页、记录和查询目标复用同一文本投影；包含比较两侧采用相同空白规范化，恢复原 `query_click` 绑定 |
| 真实短状态被拒读 | 历史“至少 24 字符”启发式把 `OK`、`已完成`、`All Buttons Clicked` 当作空白来源 | 共享可读性谓词允许已观察、非加载壳的当前页面短文本；普通抓取阈值、空白/挑战/登录/HTTP 错误拒绝规则保留 |

恢复条件直接从原 committed/durable 回执计算，比较复用原进度规范化函数。页面文本、输入值或控件启用状态变化，以及两次导航间发生其他交互时，不启用该恢复。程序不代选业务按钮，不把显式重载改成点击，也不把未完成判为成功。恢复展示随着下一轮实际事实重新计算，不引入第二套恢复状态。

普通模式曾尝试给所有页面修改动作自动读取，回归发现它会给模型自写的“原子点击→等待→读取”插入多余读取。本轮已收窄为显式 `purpose=controls` 计划；手写原子 CodeMode 仍自行拥有等待和读取。研究模式原有取证/提交约束继续有效，已有 read 计划不会再被追加一份 read。

## 类型和边界

本轮文件清单为 `.tmp-browser-recovery-files.json`，12 个 Python 文件。整文件严格 mypy（含 `disallow_any_expr`）、Pyrefly、ty 和 AST 检查覆盖显式/隐式动态类型、裸泛型、未注解函数、未限定参数的 Callable、cast 和类型检查抑制。第三方 Playwright 数据以明确的 object 返回边界读取，再验证/解码；旧测试的动态 Page mock 改为真实类型，未用 cast 或 ignore。

本轮文件三种类型检查均为零错误；AST 检查无违规。全树 Ruff 通过；全树 mypy 17,957 条错误（1,250 文件，扫描 2,578 文件），Pyrefly 21,062 条错误，ty 4,909 条诊断。全树历史债不作为阻塞，计数也受同工作区其他任务持续修改影响。完整日志为 `.tmp-browser-recovery-{ruff,mypy,pyrefly,ty}-full-final.log`；最终本轮类型日志为 `precision-fifth`、`pyrefly-fifth`、`ty-fifth`，AST 为 `ast-verified`。

程序现在承担控件引用绑定、重复状态比较、恢复菜单、控件等待、正式读取、源列表项数及回执统计。业务目标选择、哪些列表回答问题，以及自然语言解释是否完全受来源支持，仍属于语义判断。程序不会因为段落存在、列表项数相等或任务显示 done 就宣布所有解释正确。

原子 CodeMode、需要显式问题参数的读取，以及可能继续变化的网页仍按其原合同执行；没有自动猜参数。控件等待的角色/名称就绪条件和原预算范围没有扩成任意网页完成判定。本轮验收证明上述具体流程可以跑通，不能外推为任意网页和任意模型输出均有保证。
