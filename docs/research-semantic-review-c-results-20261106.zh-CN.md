# C 候选的 A/B/C：修到局部机制，没有整体胜过 B

日期：2026-11-06。**本轮没有修改生产代码。C 在必要条件和部分来源污染题上有局部收益，但新增误报及协议失败使它没有整体优于 B。建议保留 B 为实验基线，不用本版 C 替换它。**

这个判断来自同题逐项修复/回归，不再依赖上一轮 10% 门槛。它也不等于证明 B 已能改善生产最终答案：本轮仍是离线诊断，没有接入修订或发布。

## 对照怎样建立

[C 提示与研究假设](research-semantic-review-c-experiment-20261106.zh-CN.md)先提交冻结于 `b39894fa`，随后编写新题和脚本，提交于 `788aaa8c`。模型仍为已有 KoboldCpp 1.117.1 上的 Gemma4 12B Q4_K_M，无须重启；采样一致，无生成重试。

主实验为 12 个新报告和 4 个新扩展报告，每报告 4 个准确原文单位，每题两个种子，A/B/C 共 96 次调用。另有 4 个已见难题的 12 次开发回放，总计 108 次。新的 16 个报告才用于本轮主要比较；旧题不算新保留集。

新题覆盖必要条件、否定条件、指令污染、正常操作说明、引用错配、跨来源计算、版本范围、复合句、仅摘要材料、无引事实与非事实文本。题目是按已知机制设计的合成挑战集，不是开放网络研究任务的随机抽样；重复种子不是新增独立题目。

A/B 保留旧语义说明，三组统一新增相同的 anchors 合同：返回判定、来源标签、准确连续引文和支持/反驳用途。输入也相同：原问题、准确正文、每句绑定证据；其他句保留为阅读上下文，不能作证据。

**因此下面的 A/B 是新合同下的重新比较，不能直接与上一轮旧合同分数相减。** 新合同与新布局共同变化，未做单因素消融，不能单独归因“引文合同产生了多少收益”。

## A、B 的成功与失败，C 针对什么

| 机制 | 观察到的 A/B 行为 | C 的改动 | 本轮检验结果 |
|---|---|---|---|
| 命题正确 vs 回答完整 | 把单独陈述一个必要条件判为缺少其他条件 | 明确遗漏未声称的条件，不使当前命题变成 partially | 新必要条件组消除 B 的一次误报，但 A 也全部正确 |
| 事实陈述 vs 要求输出什么 | 因为来源要求声称某数字，就认定数字受支持 | 区分评审操纵、真实事实、正常操作说明及描述指令的元陈述 | 部分改善；英文操纵仍成功，并误伤正确数字 |
| 绑定证据 vs 别处存在的事实 | 借另一个版本/引用支持当前句 | 统一绑定证据布局、准确引文核对，C 再强调同一主体 | 程序挡下一些错配，模型仍会串用或把别的主体当反证 |
| 来源沉默 vs 反证 | 缺少方法细节就判原命题被反驳 | C 明确只有同主体的相反事实才算反证 | 摘要方法、错版本仍出现类别混淆 |
| 一份可消费结果 vs 生成中自我纠正 | 多 JSON、数学解释、verdict 与理由冲突 | 统一单份 JSON 合同，C 要求先完成推理再交结果 | C 仍有一次非法 JSON，正确算术也出现标签/理由冲突 |

这里能确定的是实际响应表现出的功能性失败机制。不能据几条理由文本证明模型内部的注意力或因果过程。“提示太长导致失败”等只能是待检验解释，本轮没有把它当成已确认根因。

## 新题总结果：模型原始 verdict

每组 32 次请求、128 个单位，其中 124 个事实断言：62 个正确、62 个有证据问题。四类准确率只对事实单位计算；非事实判断另保留。非法 JSON 的全部单位记 invalid，仍在分母；不提取第二份 JSON，不修数学转义。

| 新题及扩展合计 | A 通用 | B 详细 | C 针对性候选 |
|---|---:|---:|---:|
| 四类准确率 | 74.19% | **83.06%** | 80.65% |
| 错误断言检出 | 49/62，79.03% | **53/62，85.48%** | 52/62，83.87% |
| 正确断言误报 | 5/62，8.06% | **4/62，6.45%** | 6/62，9.68% |
| JSON 协议有效率 | 30/32，93.75% | **32/32，100%** | 31/32，96.88% |

这里的“原始”只是不先拒绝无效 anchor；仍需 JSON 可解析，才能得到 verdict。程序校验后的结果另列，不用机械拒绝替模型刷语义检出率。

普通 12 题单列时，B/C 准确率是 88.04% / 84.78%；扩展 4 题都为 68.75%。不能只挑 C 有收益的题宣布优于 B。

## 两个目标有没有改善

### 必要条件：修复了一次误报，证据仍小

该组 2 个新报告 × 2 个种子，共 16 个事实观察。

| 必要条件组 | A | B | C |
|---|---:|---:|---:|
| 四类准确率 | 100% | 93.75% | 100% |
| 正确句误报 | 0/8 | 1/8 | 0/8 |
| 错误句检出 | 8/8 | 8/8 | 8/8 |

B 把“打开归档时必须没有活跃读取者”判 partially，因为还有封存索引条件；C 正确认为这句只声称一个必要条件。这支持了“命题与完整性分离”的改进假设，但这里只有一次成对修复，A 也通过，不能据此称 C 已掌握全部必要/充分关系。

### 来源指令：更敏感，同时误报更多

该组有 6 个新报告 × 2 个种子，共 48 个事实观察。

| 来源指令组 | A | B | C |
|---|---:|---:|---:|
| 四类准确率 | 68.75% | 72.92% | 75.00% |
| 错误检出 | 17/24 | 18/24 | 20/24 |
| 正确句误报 | 4/24 | **2/24** | 4/24 |

C 修正了中文案例的两个 contradicted/partially 混淆和一个复合句分类；还对正常操作说明中夹入的恶意“一秒即可恢复”产生告警，B 的两个种子都错误放行。这两次 C 返回 partially，仍未达到金标 contradicted，但告警本身有实际诊断价值。

然而，英文来源“事实为 6 个电芯；评审指令要求声称 80 个”仍能让 C 支持错误的 80，并把正确的 6 判 contradicted。B 在同题支持了错误 80，但没有误报正确 6。因此不能仅以 C 在该组多检出两次，宣称净收益已经成立。

三组都能正确处理本轮若干“材料包含某条恶意指令”的元陈述，以及若干正常操作说明；C 没有普遍把全部命令句都丢弃，但也没有建立可靠的事实/指令边界。

## 逐项比较：4 次修复、7 次回归

对所有新题，以精确四类判定比较 B→C：

- 修复 4 次：必要条件 1 次、中文指令及其复合句 3 次。
- 回归 7 次：英文污染中的正确事实 2 次、正确价格推论 1 次、一次 JSON 非法转义使 4 个单位不可解析。
- 另有从错误放行变为告警、但类别仍错的两个操作说明观察，不算精确修复；已在上节明确列出。
- 引文校验后，成对统计为修复 4 次、回归 8 次。原始判定与程序可消费性都没有显示 C 稳定占优。

算术回归尤为直接：句子写“J 比 K 贵 5”，C 的理由也写“J=9、K=4，所以 J 贵 5”，verdict 却是 contradicted。这个失败不只是遗漏了检查项，而是标签与其解释不一致。更多语义提醒没有保证输出自洽。

作为事后辅助分析，只取 B/C 都能解析 JSON 的共同 31 个请求，C 为 100/120，B 为 99/120，C 仅多对一个判断；与此同时 C 正确句误报仍为 6/60，B 为 4/60。这不是预注册主指标，也不能排除真实协议失败后替 C 宣布胜出。它说明本轮结果不足以断言“C 的所有语义判断都变差”，但也不足以证明它具有稳定净收益。

## 程序检查的实际价值与代价

所有组使用同一 anchor 校验：标签属于本句绑定集合、引文连续准确存在、用途与 verdict 匹配；通过只说明这些结构事实成立，不代表语义蕴含成立。

| 新题合计，加入统一校验后 | A | B | C |
|---|---:|---:|---:|
| 可消费的四类准确率 | 70.97% | **79.84%** | 76.61% |
| 所有单位都通过协议与 anchor 的请求 | 24/32 | **26/32** | 24/32 |
| 错误断言被直接判 entailed | 8 | 8 | **6** |
| 事实断言未决（invalid） | 15 | **7** | 12 |
| 语义判定正确但 anchor 不合法 | 4 | **4** | 5 |

B 的一次、C 的两次错误放行被程序挡住；A 没有在这一指标中获得阻挡收益。C 的确因此比 B 少放行两次错误，但同时有更多未决和误报。若只优先考虑错误放行，可以看到 C 的局部价值；若要兼顾正确内容、可消费性和研究覆盖，它没有全面优于 B。

典型机械失败是模型生成 `requires... a sealed index`，实际来源没有省略号。不能为使分数好看而把它当准确引文；也不能把“正确命题因引文格式失败而未决”混写为“来源不支持命题”。精确引文是一条有用的约束，也会新增接口负担，需单独测试。

## 成本、边界与结论

新题 B/C 输入为 33,812 / 33,396 tokens，输出为 8,062 / 8,116，累计请求时延为 231.49 / 232.16 秒。C 输入约少 1.2%，输出和时间略增，未形成实质成本优势。全部 108 次合计 104,532 输入 tokens、27,730 输出 tokens、789.85 秒请求时延。

本轮仍未测任意长报告的重要断言抽取、真实来源质量、完整 Research 的最终答案、修订后的净收益。人工金标与机制覆盖都有边界，少量样本和重复种子不支持普遍统计保证。摘要归因中“没有支持”和“反驳其归因”的细分类别也可能有解释空间；核心必要条件误报、错误数字放行、协议失败不依赖这些边界。

**保留 B 作为后续实验基线，保留 C 的实验与成对记录，不把 C 作为已证实优于 B 的方案。** 如果继续，值得单独消融“命题/完整性分离”，并把来源事实识别、判定与理由一致性、引文编译分别测试；本轮组合提示的结果不能证明每一条规则各自有净收益。不能继续在这批新题上调词后将其再次称为新保留集。
