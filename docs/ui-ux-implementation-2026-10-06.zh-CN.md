## 已落地

1. 桌面窗口显式启用原生文字选择。长回答默认展开，Collapse/Expand 使用可键盘操作的文本按钮。
2. 草稿按会话在内存中保存，包括选区；切换恢复，删除会话时清理。提交锁防止重复发送；服务器受理后才消费提交快照，新增文字不被覆盖。失败保留草稿，Retry 使用原提交内容。Choose folder 只修改上下文。
3. 输入框和底部操作栏合为一个灰色外框。发送/停止同位，34px 点击目标、16px 图标。模型菜单补焦点、方向键、Enter、Escape 及滚动边界，不增加后端不支持的选项。按用户复检意见移除模型搜索输入框，菜单直接聚焦当前模型；会话搜索改为放大镜 + Search，点击原位展开同高输入框。Enter 提示靠近发送按钮，恢复原来的纸飞机图标。
4. 运行归属显示 Running in <chat> · Open，Stop 命名同一会话。审批提示定位原命令卡，输入框的 Enter 不会批准。会话切换恢复阅读位置；阅读历史时不被新输出拉到底，提供 Back to latest。未变消息保留 DOM 与选择/折叠状态。
5. 会话标题/项目名称本地搜索；命中组临时展开。Changes 标识项目与 Working tree/Snapshot，Research 标识会话。切换上下文关闭旧抽屉，迟到的加载/恢复结果不覆盖新对象。变更摘要的文件链接定位并展开对应 diff。

补充：键盘焦点提示、隐藏区域 inert、菜单/抽屉 Escape 返回焦点、窄窗口侧栏默认收起、减弱动态效果。旧桌面缓存会混用旧 CSS/JS 与新 HTML，因此静态资源 URL 加入内容修订值，并补回归测试。
