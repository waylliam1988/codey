# 开放协作学习：冻结协议 v1

冻结于首次实机调用前。此实验验证同次回答的开放内容学习闭环，不比较 Hebbian、向量或 Hopfield 排序优劣，不声称统计显著性。

- 假设：用户明确提出、可逐字归因的条件式要求，可通过普通 `done` 的可选字段留在现有 Inbox，并影响后续正常 Chat；不用开发者枚举偏好内容，不增加模型请求。
- 自变量：流式/非流式；同一已学习状态的 admission 开启/关闭；当前临时指令、修订、反馈、遗忘。
- 模型：运行前后核对 `/v1/models`；KoboldCpp Gemma4-12B Q4_K_M，`127.0.0.1:5001/v1`，temperature=0，native tools，output=4096，context=262144，reserve=32768，keep_recent=32000。每个请求最多一次尝试，不自动重发。
- 样本：两条独立的 13 回合轨迹，共 26 次生成；每回合重启 AppContext 与 provider，正常 durable task 入口，无人工预填学习字段。两个条件要求（比较方案/修复错误）使用未加入生产枚举的文字。跨项目探测使用新会话，关闭 admission 的探测也使用新会话，避免历史文本冒充独立来源。
- 主要指标：两个条件下的实际回答开头；临时覆盖；修订后行为；遗忘后不再使用旧开头；turn-only 不延续；明确反馈是否绑定已曝光的实际回答；引用示例是否被误学。
- 对照：同一学习状态关闭 admission 后的方案任务，预期不会使用保存的开头。这是上下文消费的机制对照，不是 RAG 性能基线。其他阶段改变历史，不能当独立重复样本。
- scorer 在脚本中冻结：对用户明确要求的完整开头做字符串前缀验证；不要求任意理由或语气被模型压成短标签，也不将流畅性计为成功。请求数必须每回合为 1；保留 summary 合同，不把对象自动转成字符串。
- 附加指标：独立来源/Inbox 状态、请求数、usage 是否存在、延迟、首个可见流式片段、私有 metadata 泄漏。原始请求、SSE 事件、terminal、display、Inbox、observations 和完整 state 只留本地；仓库写脱敏结果。
- 停止：服务异常、非 done、额外请求立即停止该次轨迹并标 INCOMPLETE；行为或提取失败继续记录后续格以定位传播影响，不能删格或用重跑覆盖。重跑用新目录、标明原因；模型错误不修改生产合同。确定性代码问题修复后，修复前结果仍保留，重跑注明版本。
- 晋级：受测入口须通过相关 scope、撤回、删除、重建、重启、并发、禁用、故障和流式隐私回归。只报告实测范围；未测模型可靠性、自然语气评价、大规模排序、Research 专用完成合同自动学习不在此实验结论内。
