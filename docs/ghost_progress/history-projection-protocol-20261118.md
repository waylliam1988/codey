# 历史投递实验：冻结协议

冻结于实现和实机请求之前。历史自动提取负结果不重跑；本轮不恢复其候选运行时。

假设：普通消费者仅接收历史用户请求和定位，项目消费者保留明确标为助手输出的相关历史，可以减少旧答案污染，同时保留项目建议及理由，不误称用户接受或验证。

三组：无 Ghost、冻结的修改前原文投递、修改后的用途投递。固定 8 个独立合成历史（4 个当前事实与旧错误冲突、4 个项目建议及归属），每组各跑非流式和流式，共 48 次单次生成；交错组别顺序。数据与旧 renderer 输出固定在 `history_projection_cases.json`。这是隔离投递影响的组件实验，参考材料为明确标识的 fixture，不冒充网页读取回执；另测正常生产入口及删除等边界。

模型为本机 `/models` 实际返回的 Gemma4-12B-QAT-Uncensored-HauhauCS-Balanced-Q4_K_M，端点 `http://127.0.0.1:5001/v1`；temperature=0，native tools，输出上限 8192，上下文 262144，reserve 32768，keep recent 32000，单次请求、无自动重试。每格新窗口，同一任务和参考材料；唯一主要变量为历史投递，流式为分层变量。Ghost 不增加生成请求。

冻结 scorer：模型通过唯一评估工具返回字符串字段 `answer/reason/user_accepted/verified`；事实格要求 answer=11:00，项目格要求 answer=quartzstore、reason=offline durability，两个归属字段均为 unknown。非法格式单列且计任务失败，不替换为宽松标签或自动纠正。事实错误只按结构化 answer 判定，纠错时引用旧错误不计传播。

报告分层任务正确率、错误传播、归属错误、格式失败、调用数、实际上报 tokens、首字和总延迟、历史字符数。服务未报 tokens 则为未知，不估算成实报。8 个历史、单模型、固定措辞限制泛化；无统计显著性或所有模型优越性声明。

停止条件：HTTP/协议服务故障保存原始请求和回执后停止自动矩阵；允许另存独立重跑，首次失败不覆盖。正常模型错误继续计分。确定性生产故障先修复并重新冻结受影响实验。净收益要求事实格错误减少且项目格无新增失败；不满足则记录负结果并调整/终止消费者变化。安全边界修复与行为收益分开报告。

## labels-v2：单独冻结的提示澄清

first 的 48 格已完成并保留：事实 answer 和项目 answer/reason 均生成完整句子，全部未通过原精确 scorer；原始回执显示参考信息及角色判断基本正确，不解释成记忆功能全部失败。初始提示没有明确枚举短标签，属于评估接口约定不足，不能据此判定事实错误或生产故障。labels-v2 保留同一 scorer、样本、三组、配置和 48 格，仅明确要求字段只能填写列出的精确标签。独立 evidence 目录，首次失败不覆盖。新增 usage sink 以记录实际上报的用量，并记录首个 JSON 回执到达时间（不是用户可见首字延迟；非流式为完整回执）。这是测量修正，不修改生产工具合同。
